# aperture's design

The design is the book's (`workspaces/tycho/missions/packages-released/designs/aperture.md`):
the options review against Wuffs, libjpeg-turbo, zune-image, libspng, fpnge and stb, the bar
each codec is held to, the streaming-by-rows architecture, the API, the limits that make an
untrusted image safe to decode, and the proof (PngSuite, libjpeg-turbo's test images, Wuffs's
GIFs, libwebp's corpus) each release meets.
